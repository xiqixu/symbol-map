# SF Film Symbol Map

A 10-minute walkthrough of how we built a D3.js proportional symbol map of film and TV locations in San Francisco (Week 09 · D3.js lab). It includes the live map, the project source with line-by-line notes, two hands-on coding tasks and a short quiz.

**Live page:** https://xiqixu.github.io/symbol-map/

**Without the code panel:** https://xiqixu.github.io/symbol-map/no-code/ (same scenes, tasks and quiz; the map takes the full right side)

Open a task directly: add `#task-1` or `#task-2` to the address.

Keys: ← → scenes · ↓ ↑ code notes · C code panel · N speaker notes · T timer · F full screen.

Sources: [Film Locations in San Francisco](https://data.sfgov.org/Culture-and-Recreation/Film-Locations-in-San-Francisco/yitu-d5am/about_data) (DataSF) · basemap [blackmad/neighborhoods](https://github.com/blackmad/neighborhoods) · [D3 7.9.0](https://d3js.org) (ISC licence), bundled in the page so it works offline.
